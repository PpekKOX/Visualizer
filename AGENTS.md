# AGENTS.md

## Overview

Visualizer is an Open-Source Web-Application with the sole purpose of visualizing code. Be it sorting algorithms or path-finding algorithms. You might know how an algorithm works logically, but you can't quite grasp the idea of which steps the code does when - and that's where Visualizer comes in clutch.

## How to work:

- Prefer simple and clean code rather than complicated systems & functions.
- Avoid long and unnecessary comments. Functions that are self-explaining do not require comments, and longer / more complicated parts that would require such please put into docs.md.
- Always use english language, wheter it is for writing functions, variables or comments.
- Before applying new code, try to understand the system as a whole.
- Apply the smallest changes necessary in order to complete a task.
- Before writing new functions / code - analyze the existing codebase, find similarities or reusable code.
- When creating a new function or system follow the rules of SRP & OCP.
- If a task has open questions or the instructions were unclear, ask questions instead of guessing what the proper solution should look like.
- Always test the code before applying it.
- When adding new features / changing existing ones always make sure to adjust docs.md / README.md.
